# Security policy

## Supported versions

Fixes land on `main` and ship in the next tagged release. Only the latest release is
supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Send a report to
ferrandodfilippo+anvil@ik.me with the affected version, the steps to reproduce and the
impact. A first reply is sent within a week.

## Security model

What anvil protects, what it trusts, and what is out of scope is described in
[docs/security.md](docs/security.md).
